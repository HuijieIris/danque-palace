# 丹阙 · 盛唐宫苑

[进入宫苑](https://huijieiris.github.io/danque-palace/)

《丹阙》是一个取意于盛唐宫阙的 Three.js 交互场景。由朱雀门进入庭院，沿中轴望向含元殿，可见金瓦重檐、朱红立柱和殿前的雕龙踏道。两侧设有回廊与钟亭，旗帜和薄雾随时间运动。

## 游览

- 拖动旋转视角，滚轮缩放，右键拖动平移，WASD 漫游。
- 点击宫门可开合，点击宫灯可点亮或熄灭，点击铜钟可使其摆动。
- 「入夜」和「破晓」切换天色、光照和宫灯。「步入庭院」将视角移到殿前。

## 本地运行

用浏览器打开 `index.html` 即可。核心建筑由代码生成，联网用于从 CDN 加载 Three.js。
